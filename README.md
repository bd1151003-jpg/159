# 唐美玥 - 亮麗極簡個人網頁 (Vibrant Minimalist Portfolio)

這是為您量身打造的**「單一檔案」亮麗風格個人網頁**。
為符合您最後提出的「精簡、亮麗風格」要求，網頁採用了現代化的 **Glassmorphism (毛玻璃)** 設計，搭配充滿活力的粉橘/粉紫漸層色彩，並將內容進行了**高度優化與精簡**，讓您的個人特色（喜歡簡單生活、認真對待事物）一眼就能被看見，同時預留了**生活照**的專屬展示空間。

## 🌟 網頁特色
1. **單一檔案 (Single-File)**: HTML、CSS、JavaScript 全部整合在 `index.html` 中，超級乾淨、無需管理多個檔案，點擊即可用瀏覽器開啟。
2. **亮麗風格 (Vibrant Style)**: 採用乾淨白底搭配浪漫活潑的粉、橘、紫漸層，背景還有緩慢飄動的色彩點綴（動態背景），整體視覺年輕且專業。
3. **精簡內容 (Streamlined Content)**: 摒棄過多冗長的文字，將您的興趣（閱讀、聽音樂、睡覺）與技能（畫一幅畫）提煉為精緻的圖文卡片，呼應您「簡單生活」的理念。
4. **生活照畫廊 (Life Gallery)**: 特別設計了 1:1 正方形網格的照片牆，預留了 3 張照片的空間，滑鼠游標移過去時會有漂亮的放大與粉色遮罩效果，非常適合放您的畫作或生活照。
5. **專屬聯絡卡片**: 整合了您的 Email、Line (`0611822147`) 與 Instagram (`_yaozx07`)，採用圓角浮雕按鈕設計，滑鼠移入會有漸層高光效果。

## 📁 檔案說明
* `index.html`: 您的專屬個人網頁 (包含所有代碼與樣式)。
* `README.md`: 本說明文件。

## 📸 圖片替換教學
請準備好您的照片，與 `index.html` 放在**同一個資料夾**內，並依照以下檔名命名：
* **大頭貼**: 命名為 `profile.jpg`
* **生活照 1**: 命名為 `life1.jpg`
* **生活照 2**: 命名為 `life2.jpg`
* **生活照 3**: 命名為 `life3.jpg`

*(註：若暫時沒有放入照片，網頁會自動顯示帶有您名字縮寫的粉色佔位圖片，不會破版！)*

## 🚀 部署指南 (免費上傳到網路上)
1. 前往 [Vercel](https://vercel.com/) 註冊並登入 (支援 GitHub 帳號快速登入)。
2. 點擊 "Add New Project"。
3. 將包含 `index.html` 與您照片的資料夾，直接拖曳到網頁上即可完成部署，立刻獲得您的專屬網址，方便貼在 IG 個人檔案上！
